# Spec Delta

## ADDED Requirements

### Requirement: Version row spacing is even
The row holding the version button SHALL have balanced vertical spacing above and below the button, at every viewport width and in both themes, and SHALL NOT leave a large empty band below it.

#### Scenario: Bottom of the landing page
- **WHEN** a visitor scrolls to the bottom of `/` at 320px, 768px and 1280px
- **THEN** the version button has visibly equal space above and below it within its row
